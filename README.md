# OAQJP Final Project - Embedded AI CI/CD Pipeline

## Project Overview
This repository contains the application source code and CI/CD automation pipeline for the Embedded AI final project.

## CI/CD Pipeline Features
- **Linting**: Automated code quality checks using `flake8`.
- **Unit Testing**: Automated unit tests and coverage reporting using `nosetests`.
- **Tekton Tasks**: OpenShift pipeline task definitions for workspace cleanup and automated testing.
- **GitHub Actions**: Automated workflow triggered on pushes and pull requests to the main branch.
